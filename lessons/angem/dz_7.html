Задание 1. Приведение к каноническому виду параллельным переносом осей

Задача 1

Определить тип кривой второго порядка, составить её каноническое уравнение и найти каноническую систему координат:

\[ 9x^2 - 16y^2 - 6x + 8y - 144 = 0 \]
Посмотреть ответ

Так как в уравнении отсутствует член с \(xy\), кривая приводится к каноническому виду параллельным переносом осей (без поворота). Найдём координаты центра, приравняв к нулю частные производные по \(x\) и \(y\), то есть коэффициенты при линейных членах после выделения полных квадратов:

\[ 18x - 6 = 0, \qquad -32y + 8 = 0 \]

откуда \(x_0 = \frac{1}{3}\), \(y_0 = \frac{1}{4}\) — центр кривой в точке \(\left(\frac{1}{3}, \frac{1}{4}\right)\).

Сделаем сдвиг \(x = x' + \frac{1}{3}\), \(y = y' + \frac{1}{4}\). Подставляя в исходное уравнение и приводя подобные, линейные члены сокращаются, и уравнение принимает вид:

\[ 9(x')^2 - 16(y')^2 - 144 = 0 \]

Разделим на 144 и обозначим \(X = \frac{x'}{12}\), \(Y = \frac{y'}{12}\) (то есть введём масштаб так, чтобы коэффициенты стали единицами):

\[ \frac{X^2}{16} - \frac{Y^2}{9} = 1 \]

Это каноническое уравнение гиперболы с полуосями \(a=4\), \(b=3\) (в единицах переменных \(X,Y\)); в переменных \(x',y'\) каноническое уравнение имеет вид \(\frac{(x')^2}{16} - \frac{(y')^2}{9} = 1\).

Тип кривой: гипербола. Каноническая система координат: начало — в точке \(\left(\frac{1}{3}, \frac{1}{4}\right)\) старой системы, базисные векторы совпадают со старыми: \(E_1=(1,0)\), \(E_2=(0,1)\) (поворота осей не было, только параллельный перенос).

Задача 2

Определить тип кривой второго порядка, составить её каноническое уравнение и найти каноническую систему координат:

\[ 9x^2 + 4y^2 + 6x - 4y - 2 = 0 \]
Посмотреть ответ

Член с \(xy\) отсутствует, поэтому достаточно параллельного переноса. Из условий обращения в нуль линейных членов после выделения полных квадратов находим центр:

\[ 18x + 6 = 0, \qquad 8y - 4 = 0 \ \Rightarrow \ x_0 = -\frac{1}{3}, \ y_0 = \frac{1}{2} \]

Сдвиг \(x = x' - \frac{1}{3}\), \(y = y' + \frac{1}{2}\) даёт после подстановки и приведения подобных:

\[ 9(x')^2 + 4(y')^2 - 4 = 0 \]

Разделим на 4 и обозначим \(X = \frac{x'}{2}\), \(Y = \frac{y'}{2}\):

\[ 9X^2 + 4Y^2 = 1 \]

Это каноническое уравнение эллипса.

Тип кривой: эллипс. Каноническая система координат: центр канонической системы — точка \(\left(-\frac{1}{3}, \frac{1}{2}\right)\) старой системы, базисные векторы \(E_1=(1,0)\), \(E_2=(0,1)\) (без поворота).

Задача 3

Определить тип кривой второго порядка, составить её каноническое уравнение и найти каноническую систему координат:

\[ 12x^2 - 12x - 32y - 29 = 0 \]
Посмотреть ответ

Здесь член с \(y^2\) отсутствует — это признак параболы. Выделим полный квадрат по \(x\):

\[ 12\left(x^2 - x\right) - 32y - 29 = 0 \ \Rightarrow \ 12\left(x - \frac{1}{2}\right)^2 - 3 - 32y - 29 = 0 \]

\[ 12\left(x - \frac{1}{2}\right)^2 - 32y - 32 = 0 \]

Выразим \(y\):

\[ y = \frac{3}{8}\left(x - \frac{1}{2}\right)^2 - 1 \]

Введём новые координаты \(X = x - \frac{1}{2}\), \(Y = y + 1\) (перенос вершины в начало координат):

\[ Y = \frac{3}{8}X^2 \]

Это уравнение параболы с осью, параллельной оси \(Oy\).

Тип кривой: парабола. Каноническая система координат: вершина — в точке \(\left(\frac{1}{2}, -1\right)\) старой системы, базисные векторы \(E_1=(1,0)\), \(E_2=(0,1)\) (без поворота).

Задание 2. Приведение к каноническому виду поворотом осей (центр в начале координат)

Задача 1

Определить тип кривой второго порядка, составить её каноническое уравнение и найти каноническую систему координат:

\[ 2x^2 + 6xy + 10y^2 - 121 = 0 \]
Посмотреть ответ

Здесь \(A=2\), \(2B=6\), \(C=10\) (коэффициент при \(xy\) равен \(2B\)), линейных членов нет — центр кривой совпадает с началом координат, поворотом уничтожаем член с \(xy\). Угол поворота \(\varphi\) находим из условия:

\[ \tan 2\varphi = \frac{2B}{A-C} = \frac{6}{2-10} = -\frac{3}{4} \]

Отсюда, восстанавливая \(\cos\varphi\) и \(\sin\varphi\) из соотношений двойного угла, получаем \(\cos\varphi = \frac{3}{\sqrt{10}}\), \(\sin\varphi = \frac{1}{\sqrt{10}}\). Формулы поворота:

\[ x = \frac{3}{\sqrt{10}}X - \frac{1}{\sqrt{10}}Y, \qquad y = \frac{1}{\sqrt{10}}X + \frac{3}{\sqrt{10}}Y \]

Подставляя эти выражения в исходное уравнение и приводя подобные, член с \(XY\) обращается в ноль (как и было задумано), а коэффициент при \(X^2\) получается равным \(\frac{23}{5}\), при \(Y^2\) — равным \(\frac{37}{5}\). Уравнение принимает вид:

\[ \frac{23}{5}X^2 + \frac{37}{5}Y^2 - 121 = 0 \]

Домножим на 5:

\[ 23X^2 + 37Y^2 - 605 = 0 \ \Leftrightarrow \ \frac{X^2}{605/23} + \frac{Y^2}{605/37} = 1 \]

Это каноническое уравнение эллипса.

Тип кривой: эллипс. Каноническая система координат: центр \((0,0)\) (совпадает со старым началом), базисные векторы в старой системе координат: \(E_1\left(\frac{3}{\sqrt{10}}, \frac{1}{\sqrt{10}}\right)\), \(E_2\left(-\frac{1}{\sqrt{10}}, \frac{3}{\sqrt{10}}\right)\).

Задача 2

Определить тип кривой второго порядка, составить её каноническое уравнение и найти каноническую систему координат:

\[ 2x^2 - 2\sqrt{3}xy + 9 = 0 \]
Посмотреть ответ

Здесь \(A=2\), \(2B=-2\sqrt3\), \(C=0\). Угол поворота:

\[ \tan 2\varphi = \frac{2(-\sqrt3)}{2-0} = -\sqrt3 \ \Rightarrow \ 2\varphi = -\frac{\pi}{3} \ \Rightarrow \ \varphi = -\frac{\pi}{6} \]

Тогда \(\cos\varphi = \frac{\sqrt3}{2}\), \(\sin\varphi = -\frac{1}{2}\). Формулы поворота:

\[ x = \frac{\sqrt3}{2}X + \frac{1}{2}Y, \qquad y = -\frac{1}{2}X + \frac{\sqrt3}{2}Y \]

Подставляя в исходное уравнение и приводя подобные, член с \(XY\) исчезает, а уравнение принимает вид:

\[ 3X^2 - Y^2 + 9 = 0 \]

Перенесём свободный член и разделим на 9:

\[ \frac{Y^2}{9} - \frac{X^2}{3} = 1 \]

Это каноническое уравнение гиперболы (с действительной осью вдоль оси \(Y\)).

Тип кривой: гипербола. Каноническая система координат: центр \((0,0)\), базисные векторы \(E_1\left(\frac{\sqrt3}{2}, -\frac{1}{2}\right)\), \(E_2\left(\frac{1}{2}, \frac{\sqrt3}{2}\right)\).

Задача 3

Определить тип кривой второго порядка, составить её каноническое уравнение и найти каноническую систему координат:

\[ x^2 - 2xy + y^2 + 2x + 2y = 0 \]
Посмотреть ответ

Здесь \(A=1\), \(2B=-2\), \(C=1\), то есть \(A=C\) — это вырожденный случай для формулы \(\tan2\varphi\), угол поворота находится из условия \(A=C\):

\[ \tan 2\varphi = \frac{2(-1)}{1-1} \ \Rightarrow \ 2\varphi = \frac{\pi}{2} \ \Rightarrow \ \varphi = \frac{\pi}{4} \]

(при \(A=C\) знаменатель обращается в ноль, что соответствует углу поворота \(2\varphi=\frac{\pi}{2}\)). Тогда \(\cos\varphi = \sin\varphi = \frac{\sqrt2}{2}\). Формулы поворота:

\[ x = \frac{\sqrt2}{2}X - \frac{\sqrt2}{2}Y, \qquad y = \frac{\sqrt2}{2}X + \frac{\sqrt2}{2}Y \]

Подставляя в исходное уравнение: квадратичная часть \(x^2-2xy+y^2 = (x-y)^2\), а \(x - y = -\sqrt2\,Y\), поэтому квадратичная часть даёт \(2Y^2\) — коэффициент при \(X^2\) обнуляется, как и должно быть при правильно выбранном угле. Линейная часть \(2x+2y = 2\sqrt2\,X\). Уравнение принимает вид:

\[ 2Y^2 + 2\sqrt2\,X = 0 \ \Leftrightarrow \ Y^2 = -\sqrt2\,X \]

Это каноническое уравнение параболы.

Тип кривой: парабола. Каноническая система координат: вершина \((0,0)\) (совпадает со старым началом, так как в исходном уравнении не было слагаемого без переменных), базисные векторы \(E_1\left(\frac{\sqrt2}{2}, \frac{\sqrt2}{2}\right)\), \(E_2\left(-\frac{\sqrt2}{2}, \frac{\sqrt2}{2}\right)\).

Задание 3. Приведение к каноническому виду: параллельный перенос и поворот осей

Задача 1

Определить тип кривой второго порядка, составить её каноническое уравнение и найти каноническую систему координат:

\[ 2x^2 - 4xy + 5y^2 + 8x - 2y + 9 = 0 \]
Посмотреть ответ

Здесь \(A=2\), \(2B=-4\), \(C=5\), есть и линейные, и смешанный члены, значит нужен и перенос центра, и поворот. Найдём центр из системы, приравнивая к нулю частные производные:

\[ 4x - 4y + 8 = 0, \qquad -4x + 10y - 2 = 0 \]

Решая систему, получаем \(x_0 = -3\), \(y_0 = -1\).

Сдвиг \(x = x' - 3\), \(y = y' - 1\) уничтожает линейные члены, и уравнение принимает вид:

\[ 2(x')^2 - 4x'y' + 5(y')^2 - 4 = 0 \]

(свободный член вычисляется подстановкой центра в исходное уравнение). Теперь поворотом уничтожаем член с \(x'y'\). Угол поворота:

\[ \tan 2\varphi = \frac{2(-2)}{2-5} = \frac{4}{3} \ \Rightarrow \ \cos\varphi = \frac{2}{\sqrt5}, \ \sin\varphi = \frac{1}{\sqrt5} \]

Подставляя формулы поворота \(x' = \frac{2}{\sqrt5}X - \frac{1}{\sqrt5}Y\), \(y' = \frac{1}{\sqrt5}X + \frac{2}{\sqrt5}Y\) и приводя подобные, получаем:

\[ X^2 + 6Y^2 - 4 = 0 \ \Leftrightarrow \ \frac{X^2}{4} + \frac{Y^2}{2/3} = 1 \]

Это каноническое уравнение эллипса.

Тип кривой: эллипс. Каноническая система координат: центр \((-3,-1)\) в старой системе, базисные векторы \(E_1\left(\frac{2}{\sqrt5}, \frac{1}{\sqrt5}\right)\), \(E_2\left(-\frac{1}{\sqrt5}, \frac{2}{\sqrt5}\right)\).

Задача 2

Определить тип кривой второго порядка, составить её каноническое уравнение и найти каноническую систему координат:

\[ 4xy - 3y^2 - 4x + 10y - 6 = 0 \]
Посмотреть ответ

Здесь \(A=0\), \(2B=4\), \(C=-3\). Найдём центр из системы уравнений (приравнивая частные производные к нулю):

\[ 4y - 4 = 0, \qquad 4x - 6y + 10 = 0 \]

Из первого уравнения \(y_0=1\), тогда из второго \(4x_0 - 6 + 10 = 0 \Rightarrow x_0=-1\). Центр — точка \((-1,1)\).

Сдвиг \(x = x' - 1\), \(y = y' + 1\) уничтожает линейные члены и даёт:

\[ 4x'y' - 3(y')^2 - 1 = 0 \]

Поворот тем же углом, что и в предыдущей задаче (совпадение коэффициентов даёт тот же \(\tan2\varphi\)):

\[ \tan 2\varphi = \frac{2\cdot2}{0-(-3)} = \frac{4}{3} \ \Rightarrow \ \cos\varphi = \frac{2}{\sqrt5}, \ \sin\varphi = \frac{1}{\sqrt5} \]

Подставляя формулы поворота \(x' = \frac{2}{\sqrt5}X - \frac{1}{\sqrt5}Y\), \(y' = \frac{1}{\sqrt5}X + \frac{2}{\sqrt5}Y\) и приводя подобные, получаем:

\[ X^2 - 4Y^2 - 1 = 0 \ \Leftrightarrow \ \frac{X^2}{1} - \frac{Y^2}{1/4} = 1 \]

Это каноническое уравнение гиперболы.

Тип кривой: гипербола. Каноническая система координат: центр \((-1,1)\) в старой системе, базисные векторы \(E_1\left(\frac{2}{\sqrt5}, \frac{1}{\sqrt5}\right)\), \(E_2\left(-\frac{1}{\sqrt5}, \frac{2}{\sqrt5}\right)\).

Задача 3

Определить тип кривой второго порядка, составить её каноническое уравнение и найти каноническую систему координат:

\[ 9x^2 - 24xy + 16y^2 - 8x + 19y + 4 = 0 \]
Посмотреть ответ

Здесь \(A=9\), \(2B=-24\), \(C=16\), и \(AC - B^2 = 9\cdot16 - 12^2 = 144-144=0\) — значит, кривая не имеет центра (это парабола), система для центра несовместна. Поэтому сначала выполняем только поворот, устраняющий член с \(xy\), а перенос сделаем позже. Угол поворота:

\[ \tan 2\varphi = \frac{2(-12)}{9-16} = \frac{24}{7} \ \Rightarrow \ \cos\varphi = \frac{4}{5}, \ \sin\varphi = \frac{3}{5} \]

Формулы поворота:

\[ x = \frac{4}{5}X - \frac{3}{5}Y, \qquad y = \frac{3}{5}X + \frac{4}{5}Y \]

Подставляя в исходное уравнение и приводя подобные, коэффициент при \(X^2\) обнуляется (как и должно быть для параболы при правильно выбранном угле), коэффициент при \(Y^2\) получается равным 25, а линейные члены преобразуются в члены с \(X\) и \(Y\). После подстановки уравнение принимает вид:

\[ 25Y^2 + 5X + 20Y + 4 = 0 \]

Выделим полный квадрат по \(Y\):

\[ 25\left(Y^2 + \frac{4}{5}Y\right) + 5X + 4 = 0 \ \Rightarrow \ 25\left(Y+\frac{2}{5}\right)^2 - 4 + 5X + 4 = 0 \]

\[ 25\left(Y+\frac{2}{5}\right)^2 + 5X = 0 \ \Leftrightarrow \ \left(Y+\frac{2}{5}\right)^2 = -\frac{1}{5}X \]

Это каноническое уравнение параболы (после переноса начала вдоль повёрнутых осей в точку \(X=0\), \(Y=-\frac{2}{5}\) в повёрнутой системе).

Найдём координаты вершины в исходной системе. В повёрнутых координатах вершина имеет \(X=0\), \(Y=-\frac{2}{5}\); переводя обратно по формулам поворота:

\[ x = \frac{4}{5}\cdot0 - \frac{3}{5}\cdot\left(-\frac{2}{5}\right) = \frac{6}{25}, \qquad y = \frac{3}{5}\cdot0 + \frac{4}{5}\cdot\left(-\frac{2}{5}\right) = -\frac{8}{25}\]

Тип кривой: парабола. Каноническая система координат: вершина — точка \(\left(\frac{6}{25}, -\frac{8}{25}\right)\) старой системы, базисные векторы \(E_1\left(\frac{4}{5}, \frac{3}{5}\right)\), \(E_2\left(-\frac{3}{5}, \frac{4}{5}\right)\).

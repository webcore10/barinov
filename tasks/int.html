Задача №1 Демидович

Посчитайте неопределенный интеграл

\[ \int \frac{dx}{\sin^2\left(2x + \frac{\pi}{4}\right)} \]

Посмотреть решение

Решение. Сделаем замену u=2x+π4, тогда du=2dx:

\[ \int \frac{dx}{\sin^2\left(2x+\frac\pi4\right)} = \frac12\int \frac{du}{\sin^2u} = \frac12\int \csc^2u\,du = -\frac12\cot u + C. \]

Ответ: \( -\dfrac12\cot\!\left(2x+\dfrac{\pi}{4}\right) + C. \) (Задача №1667 в задачнике Демидовича.)

Задача №2 MIT Integration Bee

Посчитайте определенный интеграл

\[ \int^{\int_0^{\int_0^{\int_0^1{xdx}}{xdx}}{xdx}}_{\int^1_{\int^1_{\int_0^1{xdx}}{xdx}}{xdx}}{xdx} \]

Посмотреть решение

Решение. Считаем пределы интегрирования изнутри наружу, используя ∫xdx=x22.

Верхний предел: ∫01xdx=12, затем ∫01/2xdx=18, затем ∫01/8xdx=1128.

Нижний предел: ∫1/21xdx=38, затем ∫3/81xdx=55128.

Значит, исходный интеграл равен

\[ \int_{55/128}^{1/128} x\,dx = \frac12\left[\left(\frac{1}{128}\right)^2-\left(\frac{55}{128}\right)^2\right]=\frac12\cdot\frac{1-3025}{16384}=\frac{-3024}{32768}=-\frac{189}{2048}. \]

Ответ: \( -\dfrac{189}{2048}. \)

Задача №3 MIT Integration Bee

Посчитайте неопределенный интеграл

\[ \int\sqrt{\frac{\cos x \cot x \csc x }{\sin x \tan x \sec x}}dx \]

Примечание. csc ⁡ x = 1 sin ⁡ x и sec ⁡ x = 1 cos ⁡ x , что редко встречается в наших учебниках.

Посмотреть решение

Решение. Раскрываем cot,csc,tan,sec через синус и косинус:

\[ \int\sqrt{\dfrac{\cos x\cdot\frac{\cos x}{\sin x}\cdot\frac1{\sin x}}{\sin x\cdot\frac{\sin x}{\cos x}\cdot\frac1{\cos x}}}\,dx=\int\sqrt{\frac{\cos^2x/\sin^2x}{\sin^2x/\cos^2x}}\,dx=\int\frac{\cos^2x}{\sin^2x}\,dx. \]

Далее

\[ \int\frac{\cos^2x}{\sin^2x}\,dx=\int\left(\frac{1}{\sin^2x}-1\right)dx=-\cot x-x+C. \]

Ответ: \( -\cot x - x + C. \)

Задача №4 MIT Integration Bee

Посчитайте неопределенный интеграл

\[ \int x^2 \sin x \, dx \]
Посмотреть решение

Решение. Дважды применяем интегрирование по частям.

\[ \int x^2\sin x\,dx = \Big[\,df=2x\,dx,\ dg=\sin x\,dx;\ f=x^2,\ g=-\cos x\,\Big] = -x^2\cos x + 2\int x\cos x\,dx. \]
\[ \int x\cos x\,dx = \Big[\,df=dx,\ dg=\cos x\,dx;\ f=x,\ g=\sin x\,\Big] = x\sin x - \int\sin x\,dx = x\sin x+\cos x. \]

Подставляя обратно:

\[ \int x^2\sin x\,dx = -x^2\cos x + 2(x\sin x+\cos x) + C = -x^2\cos x+2x\sin x+2\cos x+C. \]

Ответ: \( -x^2\cos x+2x\sin x+2\cos x+C. \)

Задача №5 MIT Integration Bee

Посчитайте неопределенный интеграл

\[ \int \operatorname{arctg}(\sqrt{x}) \, dx \]
Посмотреть решение

Решение. Интегрируем по частям: f=arctg(x), dg=dx, тогда g=x, а

\[ df = \frac{1}{1+x}\cdot\frac{1}{2\sqrt x}\,dx = \frac{dx}{2\sqrt x(1+x)}. \]
\[ \int \operatorname{arctg}(\sqrt x)\,dx = x\cdot\operatorname{arctg}(\sqrt x) - \int \frac{x\,dx}{2\sqrt x(1+x)} = x\operatorname{arctg}(\sqrt x) - \int\frac{\sqrt x\,dx}{2(1+x)}. \]

В последнем интеграле делаем замену t=x, x=t2, dx=2tdt:

\[ \int\frac{\sqrt x\,dx}{2(1+x)}=\int\frac{t\cdot2t\,dt}{2(1+t^2)}=\int\frac{t^2\,dt}{1+t^2}=\int\left(1-\frac1{1+t^2}\right)dt=t-\operatorname{arctg}t+C=\sqrt x-\operatorname{arctg}(\sqrt x)+C. \]

Значит,

\[ \int \operatorname{arctg}(\sqrt x)\,dx = x\operatorname{arctg}(\sqrt x) - \sqrt x + \operatorname{arctg}(\sqrt x) + C. \]

Ответ: \( x\cdot\operatorname{arctg}(\sqrt x) - \sqrt x + \operatorname{arctg}(\sqrt x) + C. \)

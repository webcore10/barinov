Задача №1

Дано целое число. Нужно развернуть порядок его цифр. Если результат выходит за границы 32-битного знакового целого, следует вернуть 0.

Пример: 123 превращается в 321, −123 — в −321, а 1534236469 после разворота вышел бы за пределы 32-битного диапазона, поэтому ответ — 0.

Посмотреть решение

Запоминаем знак числа отдельно и работаем дальше с его модулем — это избавляет от лишних проверок на знак минуса при развороте цифр.

Переводим модуль числа в строку, разворачиваем эту строку и превращаем обратно в число, домножая на исходный знак.

Наконец, сравниваем получившееся число с границами 32-битного знакового диапазона (от −2^31 до 2^31 − 1); если оно вышло за эти границы, по условию задачи возвращаем 0, иначе — сам результат.

def reverse_number(x):
    sign = -1 if x < 0 else 1
    digits = str(abs(x))[::-1]
    reversed_value = sign * int(digits)
    if reversed_value < -2**31 or reversed_value > 2**31 - 1:
        return 0
    return reversed_value
Задача №2

Дано целое число. Нужно определить, является ли оно степенью числа 3 (то есть равно ли оно 3 в некоторой неотрицательной целой степени).

Пример: 27 = 3³ — степень тройки (True), а 45 не представимо как степень тройки (False).

Посмотреть решение

Неположительные числа сразу отбрасываем: степени тройки всегда положительны.

Дальше, пока число делится на 3 без остатка, продолжаем делить его на 3 — по сути, «снимаем» с числа множители тройки один за другим.

Если после всех делений осталась ровно единица, значит исходное число было представимо как 3 в какой-то степени; если же в какой-то момент число перестало делиться на 3 нацело, не дойдя до единицы, — оно степенью тройки не является.

def is_power_of_three(n):
    if n <= 0:
        return False
    while n % 3 == 0:
        n //= 3
    return n == 1

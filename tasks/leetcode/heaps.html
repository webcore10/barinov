Задача №1

Дан неотсортированный массив чисел и число K. Нужно найти K-й по величине элемент (то есть элемент, который оказался бы на K-м месте, если бы массив отсортировали по убыванию).

Пример: для массива [3, 2, 1, 5, 6, 4] и K = 2 ответ — 5 (по убыванию массив выглядит как [6, 5, 4, 3, 2, 1], и на втором месте стоит 5).

Посмотреть решение

Заводим мин-кучу размера K из первых K элементов массива — в ней хранятся K наибольших на данный момент увиденных чисел, а на вершине кучи всегда оказывается наименьшее из них.

Затем поочерёдно просматриваем оставшиеся элементы массива: если очередное число больше вершины кучи, значит оно входит в число K наибольших, и мы заменяем им вершину (после чего куча сама восстанавливает порядок).

После просмотра всего массива в куче остаются ровно K наибольших чисел, а на её вершине — наименьшее среди них, то есть как раз K-е по величине число.

import heapq


def kth_largest(nums, k):
    heap = nums[:k]
    heapq.heapify(heap)
    for value in nums[k:]:
        if value > heap[0]:
            heapq.heapreplace(heap, value)
    return heap[0]
Задача №2

Даны K отсортированных по возрастанию связных списков. Нужно объединить их в один отсортированный список.

Пример: для списков 1 → 4 → 5, 1 → 3 → 4 и 2 → 6 результат слияния — 1 → 1 → 2 → 3 → 4 → 4 → 5 → 6.

Посмотреть решение

Кладём в мин-кучу по одному узлу от каждого из K списков — а именно их текущие «головы». Куча в любой момент хранит наименьший из ещё не использованных элементов.

На каждом шаге забираем из кучи узел с наименьшим значением и присоединяем его к концу результирующего списка. Если у этого узла есть следующий элемент в его исходном списке, кладём этот следующий элемент в кучу вместо забранного.

Повторяем, пока куча не опустеет — это происходит ровно тогда, когда все узлы всех списков уже перенесены в результат, причём в отсортированном порядке.

import heapq


def merge_k_lists(lists):
    heap = []
    for index, node in enumerate(lists):
        if node:
            heapq.heappush(heap, (node.value, index, node))

    dummy_head = object()
    tail = None
    result_head = None
    while heap:
        value, index, node = heapq.heappop(heap)
        if tail is None:
            result_head = node
        else:
            tail.next = node
        tail = node
        if node.next:
            heapq.heappush(heap, (node.next.value, index, node.next))
    return result_head

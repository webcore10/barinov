Leetcode: Битовые операции

Задача №1

Дан массив, в котором каждое число встречается ровно два раза, кроме одного, которое встречается один раз. Нужно найти это число за линейное время и без дополнительной памяти.

Пример: для массива [4, 1, 2, 1, 2] ответ — 4, так как 1 и 2 встречаются дважды, а 4 — один раз.

Посмотреть решение

Ключевое свойство операции XOR: число в XOR с самим собой даёт ноль, а число в XOR с нулём даёт само это число. Кроме того, XOR коммутативен и ассоциативен — порядок применения не важен.

Если применить XOR последовательно ко всем элементам массива, то все числа, встречающиеся парами, взаимно «сократятся» до нуля, независимо от того, в каком порядке они шли.

В результате в накопленном значении останется только то число, у которого не было пары — это и есть ответ.

def single_number(nums):
    result = 0
    for value in nums:
        result ^= value
    return result
Задача №2

Даны два целых числа. Нужно вычислить их сумму, не используя арифметические операторы сложения и вычитания.

Пример: add(2, 3) должно вернуть 5, а add(-1, 1) — 0.

Посмотреть решение

Сложение в столбик можно повторить на уровне битов: XOR двух чисел даёт «сумму без учёта переносов» (там, где ровно один из битов единица, в сумме получаем 1, как в сложении без переноса), а операция AND со сдвигом влево на один бит даёт как раз сами переносы, которые нужно добавить дальше.

Поэтому повторяем: сначала считаем сумму без переноса (XOR) и сам перенос (AND, сдвинутый на 1), затем делаем перенос новым слагаемым и повторяем процесс — пока переносить больше нечего.

Маска на 32 бита нужна, чтобы корректно работать с отрицательными числами: Python использует числа произвольной длины, а не фиксированные 32 бита, поэтому в конце мы вручную приводим результат к диапазону обычного 32-битного целого со знаком.

def add(a, b):
    mask = 0xFFFFFFFF
    while b & mask:
        carry = (a & b) << 1
        a = (a ^ b) & mask
        b = carry & mask
    return a if a <= 0x7FFFFFFF else ~(a ^ mask)

Leetcode: Проектирование структур данных

Задача №1

Нужно спроектировать кеш ограниченной вместимости с операциями get(key) и put(key, value). Обе операции должны работать быстро; когда кеш переполняется, должна вытесняться запись, к которой дольше всего не обращались.

Пример: кеш вместимостью 2: put(1,1), put(2,2), get(1) → 1, put(3,3) (вытесняет ключ 2, так как к нему дольше всего не обращались), get(2) → −1 (запись уже вытеснена), get(3) → 3.

Посмотреть решение

Нужна структура, которая одновременно даёт быстрый доступ по ключу и помнит порядок «свежести» обращений к записям.

Словарь OrderedDict в Python как раз подходит: он хранит пары ключ-значение и дополнительно помнит порядок их добавления, а метод move_to_end позволяет за один шаг переместить запись в конец, отметив её как самую свежую.

При каждом обращении (и через get, и через put) нужная запись перемещается в конец — значит, в начале словаря всегда остаётся самая давно не использованная запись. Именно её и нужно удалить (метод popitem(last=False)), если после добавления новой записи вместимость кеша превышена.

from collections import OrderedDict


class LRUCache:
    def __init__(self, capacity):
        self.capacity = capacity
        self.cache = OrderedDict()

    def get(self, key):
        if key not in self.cache:
            return -1
        self.cache.move_to_end(key)
        return self.cache[key]

    def put(self, key, value):
        if key in self.cache:
            self.cache.move_to_end(key)
        self.cache[key] = value
        if len(self.cache) > self.capacity:
            self.cache.popitem(last=False)

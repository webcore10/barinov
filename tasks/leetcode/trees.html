Leetcode: Деревья

Задача №1

Дано бинарное дерево. Нужно найти его максимальную глубину — длину самого длинного пути от корня до листа, измеренную в количестве узлов.

Пример: для дерева с корнем 3, левым потомком 9 (без детей) и правым потомком 20 (у которого есть дети 15 и 7), максимальная глубина равна 3 — путь 3 → 20 → 15 (или 3 → 20 → 7).

Посмотреть решение

Глубина дерева с корнем в некотором узле складывается из единицы (сам этот узел) и наибольшей из глубин двух его поддеревьев.

Рекурсивно вычисляем глубину левого и правого поддерева, берём максимум из них и прибавляем единицу за текущий узел.

Базовый случай рекурсии — пустое дерево (узел None): его глубина по определению равна нулю, на этом рекурсия останавливается.

def max_depth(node):
    if node is None:
        return 0
    return 1 + max(max_depth(node.left), max_depth(node.right))
Задача №2

Дано бинарное дерево. Нужно построить его зеркальное отражение — для каждого узла поменять местами левое и правое поддеревья.

Пример: дерево 4(2(1,3), 7(6,9)) после отражения превращается в 4(7(9,6), 2(3,1)) — то есть каждая пара потомков меняется местами на всех уровнях.

Посмотреть решение

Для текущего узла нужно поменять местами ссылки на левое и правое поддерево, но сначала (или одновременно) то же самое должно произойти и внутри этих поддеревьев — иначе отражение получится только на верхнем уровне.

Поэтому рекурсивно вызываем инверсию для левого и правого поддерева, а результаты этих вызовов записываем «крест-накрест»: левым потомком становится развёрнутое правое поддерево, а правым — развёрнутое левое.

Для пустого узла (None) отражать нечего, поэтому функция просто возвращает None — это базовый случай.

def invert_tree(node):
    if node is None:
        return None
    node.left, node.right = invert_tree(node.right), invert_tree(node.left)
    return node

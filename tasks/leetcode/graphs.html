Задача №1

Дана прямоугольная сетка из символов «1» (суша) и «0» (вода). Остров — это область из единиц, соединённых по вертикали или горизонтали. Нужно посчитать количество островов на сетке.

Пример: для сетки 11000 11000 00100 00011 ответ равен 3: два острова в верхнем левом углу и по центру — по одному, плюс отдельный остров из двух клеток в правом нижнем углу.

Посмотреть решение

Проходим по всем клеткам сетки по очереди. Как только встречаем клетку с сушей, которую ещё не учитывали, — это новый остров, и счётчик увеличивается на единицу.

Сразу после этого «затапливаем» весь найденный остров: рекурсивно обходим все соседние клетки суши (сверху, снизу, слева, справа) и помечаем их как воду, чтобы не посчитать их ещё раз при дальнейшем переборе сетки.

Когда основной перебор клеток закончится, счётчик будет содержать итоговое количество островов — все клетки давно посчитанных островов к этому моменту уже помечены как «0».

def count_islands(grid):
    if not grid:
        return 0
    rows, cols = len(grid), len(grid[0])

    def flood_fill(r, c):
        if r < 0 or r >= rows or c < 0 or c >= cols or grid[r][c] != '1':
            return
        grid[r][c] = '0'
        flood_fill(r + 1, c)
        flood_fill(r - 1, c)
        flood_fill(r, c + 1)
        flood_fill(r, c - 1)

    islands = 0
    for r in range(rows):
        for c in range(cols):
            if grid[r][c] == '1':
                islands += 1
                flood_fill(r, c)
    return islands
Задача №2

Дано количество курсов и список пар вида «чтобы изучать курс A, нужно сначала изучить курс B». Нужно определить, можно ли пройти все курсы, то есть нет ли среди зависимостей цикла.

Пример: при 2 курсах и зависимости [[1, 0]] (курс 1 требует курс 0) пройти всё можно — ответ True. А при зависимостях [[1, 0], [0, 1]] курсы взаимно требуют друг друга — образуется цикл, и пройти всё нельзя — ответ False.

Посмотреть решение

Строим ориентированный граф: вершины — это курсы, а ребро идёт от курса к тому курсу, который является для него предпосылкой.

Ищем в этом графе цикл при помощи обхода в глубину с раскраской вершин в три цвета: белый — ещё не посещали, серый — вершина находится на текущем пути обхода (мы «внутри» неё), чёрный — обход этой вершины и всех её потомков полностью завершён.

Если во время обхода мы попадаем в серую вершину — значит, мы вернулись туда, откуда уже шли, то есть нашли цикл, и расписание невыполнимо. Если же обход всех вершин завершается без такой ситуации, циклов нет, и пройти все курсы можно.

def can_finish(num_courses, prerequisites):
    graph = {i: [] for i in range(num_courses)}
    for course, prereq in prerequisites:
        graph[course].append(prereq)

    WHITE, GRAY, BLACK = 0, 1, 2
    color = [WHITE] * num_courses

    def has_cycle(node):
        color[node] = GRAY
        for neighbor in graph[node]:
            if color[neighbor] == GRAY:
                return True
            if color[neighbor] == WHITE and has_cycle(neighbor):
                return True
        color[node] = BLACK
        return False

    return not any(color[i] == WHITE and has_cycle(i) for i in range(num_courses))

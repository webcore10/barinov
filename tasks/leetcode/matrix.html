Leetcode: Матрицы

Задача №1

Дана квадратная матрица n×n. Нужно повернуть её на 90 градусов по часовой стрелке, не используя дополнительную матрицу.

Пример: матрица [[1,2,3],[4,5,6],[7,8,9]] после поворота на 90° по часовой стрелке становится [[7,4,1],[8,5,2],[9,6,3]].

Посмотреть решение

Поворот квадратной матрицы на 90° по часовой стрелке можно разложить на два более простых шага.

Сначала транспонируем матрицу — отражаем её относительно главной диагонали, меняя местами элемент (i, j) с элементом (j, i) для всех пар i < j.

Затем разворачиваем каждую строку получившейся матрицы задом наперёд. Комбинация этих двух простых операций даёт в точности поворот на 90° по часовой стрелке, и всё это можно сделать без создания новой матрицы.

def rotate(matrix):
    n = len(matrix)
    for i in range(n):
        for j in range(i + 1, n):
            matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
    for row in matrix:
        row.reverse()
Задача №2

Дана прямоугольная матрица m×n. Нужно вернуть список её элементов в порядке обхода по спирали — по внешнему кольцу внутрь.

Пример: для матрицы [[1,2,3],[4,5,6],[7,8,9]] результат обхода по спирали — [1, 2, 3, 6, 9, 8, 7, 4, 5].

Посмотреть решение

Держим четыре границы ещё не пройденной части матрицы: верхнюю и нижнюю строку, левый и правый столбец.

На каждом «витке» спирали последовательно проходим верхнюю строку слева направо, затем правый столбец сверху вниз, затем (если снизу ещё осталась непройденная строка) нижнюю строку справа налево, и наконец (если слева ещё остался столбец) левый столбец снизу вверх.

После каждого из четырёх проходов соответствующая граница сдвигается внутрь матрицы на единицу. Цикл продолжается, пока верхняя граница не окажется ниже нижней или левая — правее правой — это и означает, что вся матрица пройдена.

def spiral_order(matrix):
    if not matrix:
        return []
    result = []
    top, bottom = 0, len(matrix) - 1
    left, right = 0, len(matrix[0]) - 1

    while top <= bottom and left <= right:
        for col in range(left, right + 1):
            result.append(matrix[top][col])
        top += 1

        for row in range(top, bottom + 1):
            result.append(matrix[row][right])
        right -= 1

        if top <= bottom:
            for col in range(right, left - 1, -1):
                result.append(matrix[bottom][col])
            bottom -= 1

        if left <= right:
            for row in range(bottom, top - 1, -1):
                result.append(matrix[row][left])
            left += 1

    return result

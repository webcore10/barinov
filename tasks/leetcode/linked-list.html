Leetcode: Связные списки

Задача №1

Дан односвязный список. Нужно определить, есть ли в нём цикл (то есть можно ли, двигаясь по ссылкам next, вернуться в уже пройденный узел), не используя дополнительную память под множество посещённых узлов.

Пример: список 3 → 2 → 0 → −4, где последний узел снова ссылается на узел со значением 2 — цикл есть, ответ True. Список 1 → 2 → 3 → None цикла не содержит — ответ False.

Посмотреть решение

Используем два указателя — «медленный» и «быстрый», — которые оба стартуют из головы списка. На каждом шаге медленный сдвигается на один узел вперёд, а быстрый — сразу на два.

Если цикла нет, быстрый указатель раньше медленного дойдёт до конца списка (получит значение None), и мы сможем сразу вернуть False.

Если же цикл есть, быстрый указатель, кружа внутри цикла, рано или поздно окажется в том же узле, что и медленный — оба указателя совпадут, и мы вернём True. Дополнительная память не нужна: хватает двух переменных-указателей.

def has_cycle(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow is fast:
            return True
    return False
Задача №2

Дан односвязный список. Требуется развернуть его так, чтобы порядок узлов стал обратным, и вернуть новую голову списка.

Пример: список 1 → 2 → 3 → None после разворота должен превратиться в 3 → 2 → 1 → None.

Посмотреть решение

Идём по списку слева направо, храня указатель previous — на уже развёрнутую часть списка, которая изначально пуста.

Для текущего узла сначала запоминаем, куда он вёл дальше (next_node), потому что сейчас мы это перезапишем. Затем разворачиваем его собственную ссылку next так, чтобы она указывала на previous — узел «встраивается» в развёрнутую часть.

После этого сдвигаем previous на текущий узел, а current — на ранее сохранённый next_node, и переходим к следующей итерации. Когда current становится None, весь список пройден, а previous указывает на новую голову развёрнутого списка.

def reverse_list(head):
    previous = None
    current = head
    while current:
        next_node = current.next
        current.next = previous
        previous = current
        current = next_node
    return previous

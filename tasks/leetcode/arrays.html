Leetcode: Массивы

Задача №1

Дан массив чисел и целевая сумма. Нужно найти индексы двух элементов массива, которые в сумме дают целевое значение.

Пример: для массива [2, 7, 11, 15] и target = 9 ответ — [0, 1], так как nums[0] + nums[1] = 2 + 7 = 9.

Посмотреть решение

Проходим массив один раз слева направо, попутно заполняя хеш-таблицу «значение → индекс» уже просмотренными элементами.

Для очередного элемента вычисляем, какое число до него не хватает, чтобы получить нужную сумму (target минус текущий элемент), и проверяем, не встречалось ли уже такое число.

Если встречалось — искомая пара найдена, и мы сразу возвращаем оба индекса. Если нет — просто добавляем текущий элемент в хеш-таблицу и переходим дальше.

def two_sum(nums, target):
    seen = {}
    for index, value in enumerate(nums):
        complement = target - value
        if complement in seen:
            return [seen[complement], index]
        seen[value] = index
    return []
Задача №2

Дан массив чисел. Нужно переместить все нули в его конец, сохранив относительный порядок остальных элементов, и сделать это на месте, не создавая новый массив.

Пример: массив [0, 1, 0, 3, 12] после перемещения нулей должен стать [1, 3, 12, 0, 0].

Посмотреть решение

Идём по массиву и подряд переносим все ненулевые элементы в его начало, отслеживая позицию insert_pos — место, куда нужно записать следующий ненулевой элемент.

После того как все ненулевые элементы «стянуты» в начало массива, позиция insert_pos указывает ровно на границу, с которой начинается «хвост».

Остаётся заполнить этот хвост нулями — так исходные нули оказываются в конце, а порядок остальных чисел не изменился.

def move_zeroes(nums):
    insert_pos = 0
    for value in nums:
        if value != 0:
            nums[insert_pos] = value
            insert_pos += 1
    for i in range(insert_pos, len(nums)):
        nums[i] = 0
